# 04 安全感图 Prompt

Create a Xiaohongshu vertical infographic card focused on safety and confidence before renaming files.

Canvas:
- Portrait mobile poster.
- Clean professional productivity style.
- Background off-white, green success accents, red warning accents used sparingly.

Main visual:
- A large preview table with columns: 状态 / 原文件名 / 新文件名.
- Some rows show green "可执行", one row shows yellow "注意", one row shows red "需处理".
- Add a shield/check visual element to represent risk blocking.

Exact Chinese text to place:
- Title: 最怕改错？先帮你拦住
- Key points:
  - 实时预览
  - 重名冲突提示
  - 非法字符检查
  - 路径过长提醒
  - 执行后可撤销
- Bottom line: 先确认，再真正改名

Visual details:
- The table should look like a Windows app preview, not a website landing page.
- Emphasize "safe before execution".

Typography:
- Chinese text must be exact and readable.
- Use clear status badges.

Avoid:
- Do not imply cloud upload.
- Do not show scary security imagery.
