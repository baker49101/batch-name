# 03 功能图 Prompt

Create a Xiaohongshu vertical feature card for a Windows batch rename desktop tool.

Canvas:
- Portrait mobile poster.
- Modern minimal SaaS/productivity infographic style.
- White background, green primary accent, dark text, subtle gray dividers.

Main visual:
- A central "规则流水线" vertical pipeline with connected steps.
- On the side, show a clean before/after preview table: 原文件名 -> 新文件名.
- Make it clear the user does not need to code.

Exact Chinese text to place:
- Title: 不写脚本，也能批量改名
- Pipeline label: 规则流水线
- Feature items:
  1. 自动编号
  2. 日期标记
  3. 关键词
  4. 查找替换
  5. 清理非法字符
  6. CSV 映射
- Bottom tag: 从上到下执行，随时调整顺序

Visual details:
- Use small icons: number list, calendar, tag, replace arrows, broom/cleaning, table/grid.
- Include a mini UI preview but keep text readable.

Typography:
- Chinese text must be clean and readable.
- Avoid placing text near edges.

Avoid:
- Do not include code snippets.
- Do not invent unrelated features.
