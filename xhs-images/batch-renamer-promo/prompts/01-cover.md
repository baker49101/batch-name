# 01 封面图 Prompt

Create a polished Xiaohongshu / RedNote vertical promo card for a Windows desktop productivity tool.

Canvas:
- Portrait mobile poster, safe for Xiaohongshu feed.
- Clean minimal productivity aesthetic, white/off-white background, subtle green accent color, light gray UI details.
- Style: modern Notion-like infographic, crisp vector-like UI mockup, soft shadows, high readability.
- No people, no cartoon mascot, no clutter.

Main visual:
- A messy pile of file-name labels on the left, transforming into a clean preview table on the right.
- Include a simplified desktop app interface preview: left import panel, middle rule pipeline, right before/after rename preview table.
- The app should feel like a real Windows local utility, practical and trustworthy.

Exact Chinese text to place:
- Big title: 文件名乱到崩溃？
- Strong subtitle: 一键批量整理回来
- Three small feature pills: 先预览 / 可撤销 / 防改错

Typography:
- Chinese text must be clear, sharp, and readable.
- Use bold sans-serif Chinese for the title.
- Keep all text inside safe margins, no cropped text.

Mood:
- Efficient, clean, reassuring, aimed at office workers, e-commerce operators, content creators, and finance/admin users.

Avoid:
- Do not use English headings.
- Do not add fake brand logos.
- Do not show unreadable tiny text.
