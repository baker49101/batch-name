# 02 痛点图 Prompt

Create a Xiaohongshu vertical infographic card about file organization pain points.

Canvas:
- Portrait mobile poster.
- Minimal productivity style, off-white background, black/dark-gray text, green highlights, light red warning accents.
- Use clean line icons and small UI fragments.

Layout:
- Top title area.
- Four pain-point blocks in a 2x2 grid.
- Each block has a small icon and a short Chinese phrase.
- Add visual contrast between chaotic file names and clean organization.

Exact Chinese text to place:
- Title: 这些文件名，真的很折磨
- Block 1: 截图一堆分不清
- Block 2: SKU 主图命名乱
- Block 3: 合同发票难归档
- Block 4: 素材越存越找不到
- Bottom line: 手动改名慢，还容易改错

Visual details:
- Block 1 icon: screenshot/image stack.
- Block 2 icon: product image file.
- Block 3 icon: invoice/contract document.
- Block 4 icon: media folder.
- Use messy example file chips such as "截图 (1).png", "final-final.pdf", "IMG_20260424.jpg" as background texture, but keep them secondary.

Typography:
- Chinese text must be exact, readable, and not distorted.
- Keep strong hierarchy: title large, blocks medium, bottom line bold.

Avoid:
- Avoid excessive decorative gradients.
- Avoid dense tiny text.
