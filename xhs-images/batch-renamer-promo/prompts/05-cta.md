# 05 引流结尾图 Prompt

Create a Xiaohongshu vertical closing CTA card for a Windows local batch file renaming tool.

Canvas:
- Portrait mobile poster.
- Minimal, clean, high-conversion social media infographic.
- White/off-white background, green primary action color, dark text.

Layout:
- Big headline at top.
- Five audience tags in the middle.
- Bottom call-to-action area with a comment bubble visual.

Exact Chinese text to place:
- Title: 谁最适合用？
- Audience tags:
  行政整理
  电商运营
  财务归档
  自媒体素材
  桌面文件控
- Value line: 批量整理文件名，少做重复劳动
- CTA: 评论区回复「重命名」
- Small line: 我把工具发你

Visual details:
- Use tidy folder/file icons, a simplified app window, and clean tags.
- CTA area should be prominent but not too salesy.

Typography:
- Chinese text must be accurate, sharp, and readable.
- Use generous spacing.

Avoid:
- Do not use fake QR codes.
- Do not mention paid pricing unless provided.
